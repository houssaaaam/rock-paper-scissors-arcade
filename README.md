## ⚡ Key Architecture & Features

This project moves far beyond standard conditional logic iterations by introducing a state-driven environment layout:

* **Dynamic Intelligence Modules (3 AI Modes):** 
    * *Classic AI:* Randomized pure entropy choice calculations.
    * *Tactician AI:* Built-in heuristic choice frequency logging that evaluates player history trends to dynamically calculate the optimal mathematical counter-move.
    * *Chaos Boss:* An unpredictable aggressive mode featuring visual scaling triggers and an increased particle density framework.
* **3-Second Blitz Mode:** An asynchronous gameplay engine managed via a strict runtime interval clock loop, forcing immediate decisions or executing automatic timeout penalties.
* **Full Multi-Language Support (EN / FR / AR):** Accommodates localization schemas, including structural layout switches dynamically formatting styles for Right-to-Left (RTL) Arabic layout rendering rules.
* **Browser-Safe Audio Layer & SFX Synth:** Implements interactive gesture security bypass logic to unlock a looping ambient track, paired with dynamic audio frequency synthesis (Web Audio API nodes) for real-time win/loss/tie retro chime generations.
* **Persistent Profile Matrix:** Utilizes unified LocalStorage data pipelines to track client profiles, customized avatars, unlocked system achievements, and lifelong win/loss ratio distributions.
